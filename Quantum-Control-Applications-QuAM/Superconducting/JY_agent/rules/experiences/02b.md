## Lesson (not an accepted setting) — 2026-10-08, workflow bd8bdcc9, run #333

First 02b on `as-qpu-10qV2_agent`, defaults, all 10 qubits multiplexed (87 s).
The plot showed clear cosine modulation for q3-q10 (about one period over
±0.9 V) and a flat but sharp dip for q1/q2, yet JY failed every qubit with
"resonator dip is not visible (median dip SNR 1.1-2.6 < 4)". The dip SNR
divided the depth by the robust spread of the row itself; at 7.5 MHz span the
~1 MHz-wide dip and the sloped background dominate that spread. Fixed to use
point-to-point noise (`robust_sigma(diff(row)) / sqrt(2)`): the same data
scores 26-49. Re-run 02b after the MCP reconnect rather than accepting #333.
