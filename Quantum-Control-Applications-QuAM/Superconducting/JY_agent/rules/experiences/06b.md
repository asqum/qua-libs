## Lesson — 2026-09-30 23:03 Asia/Taipei: a NaN echo fit crashes the JY worker

- Workflow `c4840bc80b3248429dec38fe7d5d8dbc`; run `49dc25a946d44902b10f338e36acc33a`;
  snapshot saved on disk as `#251` (`D:\QM\qualibrate\data\2026-09-30\#251_06b_T2_echo_230308`)
  but not registered by JY.
- Parameters: q1–q8, half-wait 16–60000 ns step 500 (plotted 0–120 us), 1000 avg,
  thermal, `use_state_discrimination=false`. Runtime 273 s.
- Plot: clean echo decays q2 9.9, q4 19.2, q6 14.9, q7 18.6, q8 27.9 us. q1 and q3
  traces RISE (inverted I-quadrature contrast) and the node's decay fit returns NaN;
  q5 is flat (T2e fit 1.97e5 us, meaningless).
- Failure: `worker.py:160` writes `runnable.state_updates` with
  `atomic_write_json(..., allow_nan=False)`; the NaN T2echo raised
  `ValueError: Out of range float values are not JSON compliant: nan`. Unrecognized
  crash → lease paused, hardware lock retained, snapshot not attached to the run.
- Fixed 2026-10-02 (JY only, node unchanged): `json_compatible` maps NaN/inf to
  None before the state-updates write; JY's sign-agnostic decay fit replaces the
  node's T2echo where it succeeds, and a value still missing fails only that qubit.
  q1/q3 rising traces are therefore expected to be recoverable on the next run.
- Do not copy this as an accepted setting.
