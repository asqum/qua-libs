## Lesson — 2026-10-14 16:34 Asia/Taipei: CRSQ_26009_die(5,-1) q3 05st crashed, data lost

- q3 (07b 51%, ~8 uV T1 contrast) at readout angle 4.498 rad (I decays; found
  empirically -- a pi shift from 2.928 did NOT invert I, +pi/2 did), T1 29.5 us.
- 100 x 1000 avg, max_wait 133 us, log, raw I: all 100 repetitions measured
  (52 min) but fit_decay_exp failed every one (decay=0), the 1-99 percentile
  filter emptied the list and the script crashed at line 297 BEFORE
  node.save -> no snapshot, the 52 min of data is lost.
- Rule of thumb: 05st needs a single-trace SNR the node fit can handle at the
  per-repetition averages; q3 has SNR ~10 only at 4000 averages. Do not run
  05st for a qubit whose 05 needed 4000 averages to pass.
